# Radios

One folder per head unit that someone has tested, named `<firmware>-<soc>-<car>` in lowercase, for example
`ts-mt6768-alfa-romeo-mito`. Each folder has:

| File | What it holds |
|---|---|
| `radio.json` | The short facts: hardware, car, Android and MainUI version, what works |
| `debloat.txt` | Packages disabled and lived with for a few days, one per line, with comments |
| `README.md` | Everything else: settings changed, quirks, what broke and how it was fixed |

To add yours, see [CONTRIBUTING.md](../CONTRIBUTING.md).
